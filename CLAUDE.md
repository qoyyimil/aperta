## UI reference
Untuk membuat UI, gunakan komponen di `ref/dealtech-ui` sebagai acuan:
- `elements/` untuk komponen dasar (button, input, card, dll.)
- `sections/` untuk bagian halaman (hero, pricing, FAQ, dll.)
- `pages/` untuk halaman utuh

Sebelum membuat UI dari nol, cari dulu komponen yang cocok di sana dan adaptasikan.
